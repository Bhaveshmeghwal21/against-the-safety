Saved episodes: base vs fine-tuned Tiny Aya

These are recorded runs, not a live model. Every system saw the same question, the same documents and the same three-search budget. "Base" is Tiny Aya Global as released; "Tuned" and "Control" are QLoRA adapters (see the project README for what each was trained on). The outcome badge is computed by the project's deterministic scorer from the gold answer and gold supporting passages, never by a language model.
